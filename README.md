# Imam Hossain — Personal Portfolio 

A futuristic, high-performance, and sci-fi-themed personal portfolio website. It showcases my journey and expertise as a **Full-Stack Software Engineer, AI Researcher, and Embedded Systems Engineer**. 

🔗 **Live Demo:**https://imamhossain01.github.io/Imam-Hossain/

## Key Features

* **Arc Reactor Skill Matrix:** An interactive, visually stunning matrix that lights up and generates an audio hum based on activated skills.
* **Hardware & IoT Lab Simulator:** A virtual lab environment demonstrating real-time data streaming and hardware enumeration (ESP32, Arduino, DHT22, etc.).
* **Cipher & Encryption Sandbox:** A live cryptographic module testing substitution-diffusion ciphers directly in the browser.
* **Interactive Certificate Gallery:** A smooth, auto-scrolling marquee gallery with a full-screen lightbox view for credentials.
* **Sci-Fi HUD Theme:** Custom UI featuring dynamic crosshairs, fluid animations, and a terminal-style contact form.

## 🛠️ Tech Stack & Technologies

* **Frontend:** HTML5, CSS3 (Custom Variables, CSS Grid/Flexbox), Vanilla JavaScript (ES6+).
* **Audio Engineering:** Web Audio API (for procedural reactor hums and interaction sounds).
* **Design Language:** Neumorphic, Sci-Fi HUD, and Cyberpunk elements.
* **Core Domains Showcased:** 
  * MERN Stack Architecture
  * Explainable AI & Machine Learning (Python, Data Models)
  * Embedded Systems (ESP32, C++, Hardware Design)
